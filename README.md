# SEO-TidY

**Free, open-source WordPress SEO and AI search readiness plugin by QvarcY.**

Clean SEO. Smarter discovery. Completely free.

> Development status: Foundation stage.
> The SEO features described below are planned and are not implemented yet.

## Vision

SEO-TidY aims to make technical SEO and content discoverability
accessible without subscriptions, premium tiers or artificial limits.

The plugin is designed for traditional WordPress websites,
with optional headless integrations possible in the future.

## Planned features

- SEO metadata engine
- Smart Schema with JSON-LD
- Technical SEO audit
- AI and answer readiness analysis
- English and Latvian localization
- Safe migration from Yoast SEO and Rank Math

## Principles

- Free and open source
- No premium features or subscriptions
- No mandatory external AI API
- No telemetry without explicit consent
- WordPress-native architecture
- Performance and accessibility first
- Explainable SEO recommendations
- Safe integration with existing plugins
